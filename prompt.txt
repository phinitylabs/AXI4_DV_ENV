ProblemSpec(
    id="axi4_environment",
    description="""Please implement a comprehensive testbench with assertions for an AXI4 (Advanced eXtensible Interface 4) environment.

The design consists of four modules:
1. axi4_top - Top-level module that instantiates master, slave, and interrupt controller
2. axi4_master - AXI4 master that initiates write and read transactions
3. axi4_slave - AXI4 slave with internal memory that responds to transactions
4. axi4_interrupt - Interrupt controller module

The testbench should be created in source/verif/agent_tb.sv and must include at least four SystemVerilog assertions that verify AXI4 protocol compliance.

AXI4 Protocol Overview:
- AXI4 uses five independent channels: Write Address (AW), Write Data (W), Write Response (B), Read Address (AR), and Read Data (R)
- Each channel uses VALID/READY handshaking
- VALID signals must remain stable until the corresponding READY is asserted
- WLAST must be asserted on the last write data transfer
- RLAST must be asserted on the last read data transfer
- Response codes: OKAY (00), EXOKAY (01), SLVERR (10), DECERR (11)

Required Assertions (create at least 4):
1. Write Address Channel: AWVALID must remain asserted until AWREADY is asserted
2. Write Data Channel: WLAST must be correctly asserted on the last data beat
3. Write Response Channel: BVALID must remain asserted until BREADY is asserted
4. Read Address Channel: ARVALID must remain asserted until ARREADY is asserted
5. Read Data Channel: RLAST must be correctly asserted with the last read data
6. Protocol Compliance: Write response must come after write data completes
7. Protocol Compliance: Read data must come after read address is accepted
8. Response Codes: BRESP and RRESP must be valid AXI4 response codes

Inputs/Outputs:
The testbench should instantiate axi4_top module with:
- clk - Clock signal
- resetn - Active-low reset signal

The testbench should monitor and verify:
- Write Address Channel signals (AWADDR, AWLEN, AWSIZE, AWBURST, AWVALID, AWREADY)
- Write Data Channel signals (WDATA, WSTRB, WLAST, WVALID, WREADY)
- Write Response Channel signals (BRESP, BVALID, BREADY)
- Read Address Channel signals (ARADDR, ARLEN, ARSIZE, ARBURST, ARVALID, ARREADY)
- Read Data Channel signals (RDATA, RRESP, RLAST, RVALID, RREADY)

The assertions should use SystemVerilog assert property statements with appropriate disable conditions for reset.
""",

    base="axi4_environment_baseline",
    test="axi4_environment_test",
    golden="axi4_environment_golden",
